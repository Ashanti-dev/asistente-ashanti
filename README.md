# Asistente Inteligente para la Innovación Pública Local

Prototipo para la Caja de Herramientas para Municipios del proyecto Municipios que Incluyen: Innovación Digital Juvenil para la Democracia Local (Ashanti Perú, FIF Perú 2026-2027).

Elaborado por Luis Alberto Vargas Tupac.

## Carpetas

- `data/`: las 8 fichas de buenas prácticas en datos estructurados, los 6 ejes temáticos y el formulario guía por perfil.
- `prompt/`: instrucciones fijas del asistente.
- `pruebas/`: casos de prueba y hojas de recomendaciones de ejemplo.
- `web/`: web pública y panel de administración (Cloudflare Pages).
- `supabase/`: migraciones y función `generar-hoja`.
